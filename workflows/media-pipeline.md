# Media Pipeline: From Idea to Published Video

## Steps

1. **Brief (Owner)**
   Goal, audience, platform, tone, deadline.

2. **Plan (Marketing agent)**
   Topic, angle, target length, call to action, and a slot in the content calendar.

3. **Production plan (Video Editor agent)**
   Script, shot list, then edit plan once footage or transcript is supplied.

4. **Copy (Marketing agent)**
   Title, caption, and hashtags based on the final video details.

5. **Review (Owner)**
   Owner approves or requests changes. Nothing is published without this step.

6. **Publish and measure (Owner + Marketing agent)**
   Owner publishes and shares the performance numbers; Marketing summarizes what worked.

7. **Evaluate (HR agent)**
   Periodically reviews samples of work, updates instructions, and logs lessons in lessons.md.

## Rules

- Every handoff is written, using the format in each agent's file
- The owner is the only approval point for public output
- When an agent is unsure, it asks instead of guessing
